# 初代產品規劃 (Product V1 / MVP Plan)

## 5. 初代產品 (MVP) 核心功能規劃

為確保產品能快速推向市場並驗證假設，MVP 將以「行動裝置優先（Mobile-First）」的網頁應用程式（PWA / Web App）形式開發，聚焦以下三大核心模塊。

## 5.1 買家端：首創「沉浸式限動」購物體驗 (Shopper UI/UX)

打破傳統電商網格狀排列，採用專為衝動購買設計的沉浸式瀏覽。

### 綜合首頁架構 (Comprehensive Home Page)

首頁是買家的核心樞紐，使用者回到首頁時即可總覽所有資訊，包含以下區塊：

#### 頂部限動導航區

首頁最上方設計類似 IG 的圓形限動群組（Story Bubbles），點擊即可直接進入主打的「動態魔術方塊瀏覽（Story Mode）」，體驗沉浸式逛街。

#### 輔助切換：傳統電商網格瀏覽 (Grid Mode)

首頁主區塊以類似傳統網購的平面排版（依活動／商品陳列）呈現，方便買家快速總覽與目的性搜尋。為延續「限時」的稀缺感，此模式下的每個活動與商品卡片都會強制加上醒目的倒數計時器／截止時間資訊。

#### 個人與賣場功能樞紐

首頁不僅展示商品，也整合以下重要模組：

- 商家資訊：展示當前代購賣家的品牌簡介與重要公告。
- 買家個人管理：包含專屬的訂單管理、購物車以及與賣家的客服聊天室入口。
- 關注賣場切換：買家可在首頁快速切換至其他已關注的代購賣家賣場，提升平台內的使用黏著度。

### 動態魔術方塊瀏覽 (Cube UI) 詳細互動設計

#### 水平點擊（點擊螢幕左右）

在同一個代購活動（Campaign）內切換不同商品。

#### 水平滑動（左右滑動方塊）

每個面代表一個不同的代購活動，例如從「韓國連線」左右切換至「日本藥妝」。切換時會顯示活動過場提示卡片。

#### 上滑展開與無縫返回 (Swipe Up & Down)

將商品卡片上滑即可展開完整的商品規格、圖文說明與庫存資訊。看完詳情後往下滑動時，系統會無縫返回至剛剛瀏覽的限動卡片與進度，不重新整理，確保流暢的逛街狀態不被打斷。

#### 快捷互動與轉化 (Bottom Actions)

畫面最下方固定顯示三個核心行動呼籲（CTA）：

- 回覆此商品：點擊後直接帶入商品資訊進入客服對話。
- 收藏／喜歡：加入願望清單。
- 加入購物車／立即下單：快速引導結帳。

#### 買家自訂篩選 (Filter & Sort)

買家可依據賣家設定好的商品類別（如：服飾、美妝）進行篩選，讓限動只播放買家感興趣的特定類別商品。

#### 結帳與金流展示

購物車支援快速結帳流程，MVP 階段展示信用卡、LINE Pay 等主流支付選項。初期可先串接測試環境或基礎 API。

## 5.2 賣家端：極速行動管理後台 (Seller Dashboard)

為賣家打造一支手機即可完成所有營運工作的管理後台。

### 雙層架構建檔系統 (Campaign & Product)

#### 活動管理 (Campaigns)

可建立不同代購活動，設定活動名稱、日期、說明、購買規範等。

#### 商品管理 (Products)

- 支援一對多關聯：一個商品可同時存在於多個不同的代購活動中。
- 彈性規格設定：賣家可自訂選項類別與選項，如顏色（紅／黑）、尺寸（S / M / L）。
- 雙重視覺資產：區分商品主圖與副圖，賦予賣家更高的展示自由度。副圖僅在買家將限時動態往上滑查看詳情時才會顯示。
- 商品分類設定：將商品歸類，以便買家使用 Filter 功能。

### 自動化訂單管理 (Order Management)

- 清晰的訂單狀態看板（待付款、已付款、待出貨、已出貨）。
- 支援快速對帳與出貨狀態更新。

### 客服訊息中心 (Message Center)

接收來自買家「回覆此商品」的訊息，系統會自動帶入該商品卡片作為引言，讓賣家一眼就知道客人在問哪件商品，實現如同回覆 IG 限動般的直覺客服體驗。

## 5.3 LINE 生態系無縫整合 (LINE Integration)

將平台與賣家賴以維生的 LINE 群組深度綁定，不改變原有社群生態，只優化效率。

### 商品一鍵廣播 (Flex Message 推播)

賣家在後台上架活動或商品後，可一鍵生成精美的 LINE 互動卡片訊息，直接發送到代購 LINE 群組中。

### 無縫喚醒購物 (LIFF 整合)

買家在 LINE 群組點擊 Flex Message 後，透過 LINE LIFF 技術直接喚醒網站的限動購買頁面，免註冊、免重新登入，直接開始滑動選購。

### 自動化狀態推播

當訂單狀態改變（如：系統確認已收到款項、賣家已出貨），系統會透過 LINE 官方帳號（Messaging API）自動發送通知給買家，大幅減少「我的貨什麼時候到？」的私訊客服成本。
