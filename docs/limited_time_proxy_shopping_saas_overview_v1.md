# 限時代購社群電商整合小助手

## 1. 專案概述 (Executive Summary)

本專案旨在為依賴 LINE 群組／社群進行「限時、連線代購」的賣家，打造一款專屬的 SaaS 營運輔助工具（小助手）。

產品將結合以下三個核心能力：

- IG 限時動態風格的商品展示
- 無縫的金流與訂單管理系統
- LINE 深度整合

目標是解決現有社群代購中資訊混亂、下單繁瑣、管理不易的痛點。核心理念是將「交易行為（上架、瀏覽、下單、管理）」獨立交由系統處理，而將「社群溫度（聊天、客服、互動）」保留在 LINE 中。

## 2. 目標受眾與痛點分析 (Target Audience & Pain Points)

### 2.1 買家端 (Consumers / Shoppers)

情境：習慣在 LINE 代購群組喊單、購買限時限量商品的消費者。

#### 資訊洗版嚴重

LINE 群組訊息量大，商品發布常與買家聊天訊息夾雜，想買的人容易錯過商品資訊。

#### 下單流程繁瑣

買家確定購買時，常需額外加賣家私帳、填寫外部表單，或經過來回私訊才能確認是否有貨與如何購買。

#### 缺乏流暢金流

通常只能使用銀行轉帳，買家需自行匯款後再截圖回報，流程斷層且體驗不佳。

### 2.2 賣家端 (Sellers / Proxy Shoppers)

情境：擁有一定客群的 LINE 群組代購主、海外連線代購主。

#### 上架與陳列效率低

缺乏能快速發布限時商品的工具，且文字配圖在 LINE 中陳列效果差，生命週期極短，容易立即被新訊息洗掉。

#### 訂單與庫存管理混亂

需要人工在對話紀錄中撈單、核對匯款截圖，極易出錯且耗時。

#### 現有電商平台不適用

蝦皮、Shopline 等傳統平台是為持久性商品設計，上架流程太重，不符合限時代購短期、快速、即時的情境。

#### 通路綁架的擔憂

賣家最大的資產是 LINE 群組內的客群，他們需要的是強化工具，而非取代 LINE 的新平台，因此無法輕易放棄現有渠道。

## 3. 核心解決方案 (Core Solutions)

### A. 專為限時代購設計的 UI/UX（買家體驗）

#### IG 限動式瀏覽體驗

首頁以類似 Instagram 限時動態（Stories）的卡片化、全螢幕滑動方式呈現商品，契合限時、快速的消費心理，讓買家專注於眼前商品的視覺衝擊，提升衝動購買率。

#### 一鍵滑動下單

在限動卡片底部直接整合「立即購買／加入購物車」按鈕，不需跳轉複雜頁面即可完成選購。

### B. 完善的交易與金流基礎建設（買家 + 賣家體驗）

#### 內建多元金流

整合信用卡、LINE Pay、虛擬帳號轉帳等自動化金流，系統自動對帳，免除人工核對匯款截圖的麻煩。

#### 即時庫存與狀態確認

買家下單當下即可確認是否有貨，無需等待賣家私訊回覆。

### C. 賣家專屬管理後台（賣家體驗）

#### 極速上架工具

支援手機端快速拍照／上傳、填寫價格與限時倒數時間，一鍵發布至平台。

#### 自動化訂單管理

提供清晰的訂單狀態面板（待付款、已付款、待出貨、已出貨），取代傳統 Excel 或記事本記帳。

### D. 渠道分離與 LINE 深度整合（營運策略）

#### 職能分離

平台負責：

- 發布商品
- 視覺瀏覽
- 下單結帳
- 訂單狀態查詢

LINE 群組負責：

- 預告互動
- 問題解答（Q&A）
- 買家許願
- 社群溫度維持

#### LINE 整合應用（LIFF / Messaging API）

- 賣家在系統發布商品時，可一鍵將精美的商品卡片訊息（Flex Message）推送到 LINE 群組。
- 買家點擊 LINE 內的商品卡片後，可無縫喚醒 Web App（LIFF）直接進入該商品的限動購買頁面，無需重新登入。
- 訂單狀態更新（如：已收到款項、商品已出貨）可透過 LINE 官方帳號自動推播通知買家。

## 4. 產品定位與商業模式 (Positioning & Business Model)

### 產品定位

本產品不是一個全新的公域電商購物中心（B2C），而是賣家的私域流量變現武裝（B2B2C SaaS）。它是一個強化現有經營模式的「小助手」工具。

### 核心賣點 (Value Proposition)

幫賣家省下 80% 的對帳與撈單時間，幫買家找回逛街的爽感，而且完全不需要離開既有的 LINE 群組。

### 商業模式預期

#### SaaS 訂閱制

賣家按月或按年支付系統使用費。

#### 抽成／手續費

透過代收代付金流賺取微薄的手續費利差。

#### 功能解鎖

基礎版可免費使用，但限制每月訂單數或功能；進階版提供完整自動化推播、高級數據分析等付費能力。
